关于素材来源

提供的两张学习通截图只包含章节标题和完成状态，不包含课程正文。本系统仅照录截图中的章节名称；知识卡和题目为独立编写、用于功能验证的演示内容，不能代表课程教师的原始材料或命题范围。

离线规则演示 · 现在即可使用
  • 检索：关键词权重 + 章节标题匹配，无向量数据库
  • 出题：来自本地结构化题库，不是实时生成
  • 调整：根据章节错误率与未作答题目选择下一题
  • 记录：浏览器 localStorage，本机保存
真实 Agent · 可选配置
  • 本地 Python 服务端接入兼容接口的模型
  • 支持真正的模型工具调用与多步检索
  • 密钥保存在服务端环境变量，不进入网页源码
  • 需模型与服务商支持工具调用，且可能产生费用

快速使用指南

  1. 输入复习目标或点击推荐主题。
  2. 查看检索到的演示知识卡与引用章节。
  3. 完成针对性选择题，系统自动记录结果并调整下一题。
  4. 切换到「学习图谱」查看薄弱点与复习建议。

仅浏览器打开 HTML 时使用离线规则模式；如需真正的大模型工具调用，请依照 README 配置并运行 Python 服务端。
