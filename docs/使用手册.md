# 《龙马智学》使用手册（原型版 V0.1）

## 一、作品介绍

本系统是一个以中央财经大学校园学习场景为背景的 Agent 复习实验原型。围绕学习通 AI 入门课程的章节标题，提供知识卡检索、练习选择、错题回访和学习图谱。仅用于验证技术思路，并非校方官方学习平台。

## 二、运行环境

离线模式：Windows / macOS / Linux 桌面浏览器，推荐 Chrome、Edge 或 Firefox 的较新版本；不需要网络和 API Key。直接双击 `dist/龙马智学-离线可运行.html`。

真实模型模式：Python 3.9+；终端设置 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`，执行 `python agent_backend.py`；在浏览器打开 `http://127.0.0.1:8765`。需要可访问、支持函数工具调用的模型接口。服务商 API 可能收费。

## 三、基本操作

1. 点击左侧“自适应复习”，输入学习目标，如“RAG和微调的区别”。
2. 系统展示匹配章节、概念梳理与核心要点。
3. 在“针对性练习”选择 A–D，回答后查看解释；点击“下一步练习”继续。
4. 点击“学习图谱”，查看各章节练习次数、正确率和建议复习范围。
5. 点击“资料与说明”了解内容来源，可导出 JSON 学习记录。

## 四、实际 Agent 功能

若配置真实模型，复习区域会显示“运行模型 Agent”按钮。点击后，系统将目标发送到本机服务端，模型可以自主选择调用 `search_notes`、`get_progress`、`select_practice` 工具；返回回答与真实工具调用记录。模型尚未配置时，该按钮不会显示。

## 五、注意事项

- 章节标题来源于参赛学习通截图，知识讲解及题目是独立编写的演示内容，不代表教师课件。
- 离线模式没有接入大语言模型，不会产生 API 费用。
- 进度默认仅保存在当前浏览器的本地存储；清除浏览数据后可能丢失。
- 本项目当前阶段尚不包含课程官方教材全文、知识向量库、错题统计的统计学置信区间或跨设备同步。
- 不要把个人 API 密钥放入网页、演示视频或提交包。
