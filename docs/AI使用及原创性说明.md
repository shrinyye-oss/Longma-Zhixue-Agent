# AI 使用及原创性说明（原型阶段）

**作品名称：**《龙马智学——校园 Agent 复习实验室》

**项目状态：** V0.1 技术验证原型，尚非最终参赛版本。

## 辅助方式

本项目在需求梳理、交互设计、UI 样式、编程实现、知识卡与练习题初稿、技术说明编写及自动化测试方面使用了生成式 AI 辅助。实际参赛提交前，需由参赛者本人阅读和验证每一处代码与内容，确保能独立讲解原理，并核实其真实性及合规性。

## 功能实现边界

离线版使用自编本地题库、关键词匹配和错题优先逻辑；不是实时调用大模型的 Agent。可选后端只有在参赛者自行配置支持工具调用的模型接口并实际成功调用之后，才可称为模型 Agent 功能。本项目不会将规则演示冒充真正的自主推理。部分接口工具调用仅经过模拟服务测试，尚未完成任何实际付费模型连接。

## 内容与素材来源

用户提供的两张学习通课程截图仅含章节标题；对应的知识解释、练习题和界面文案是演示性原创编写内容，不来自课程正文，也不能替代教师授课材料。没有复用学校官网的校徽、第三方人物形象或受版权保护的美术素材。

调研参考的开源项目：`langchain-ai/langgraphjs` 和 `microsoft/ai-agents-for-beginners` 均采用 MIT 许可证；当前原型未直接复制其源码。

## 参赛注意事项

如后续引入真实课程资料，需要确认资料的使用授权与引用要求；如果把模型回答用于自动评分，应检查准确性和鲁棒性。作品的最终原创性和提交合规性由参赛者自行核验。
